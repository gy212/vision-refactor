## 2. 切分、基线容错与考试/练习计时表现

`core/evaluation/action_catalog.py`、`action_timing.py`、`kick_events.py` 与 `kick_phases.py` 统一将 `step_front_low_kick`、`front_low_kick` 与 `rear_low_kick` 接入同一套侧面标定管线 `timing="side_kick"`（`timing_views=("side",)`）：其中 `step_front_low_kick` 与 `rear_low_kick` 开启逐次切分（`scoring="per_repetition"`），单独 `front_low_kick` 复用同一侧视击腿事件与相位划分而不做逐次拆段（`scoring="whole_clip"`）。

- **切分与抗干扰策略**：采用侧视相对脚踝高度差（滞回阈值 `enter=0.25, exit=0.14, peak=0.48, min_dur=0.35s, merge_gap=0.35s`）、短缺口插值、`abs_sup_rel` 防中段左右脚标签翻转截断（`kicking_leg_side_safe` 按双侧均有效帧分母统计互换比例），以及缺失脚踝时基于有效 `foot_index`/`knee` 的复合抬腿保持，并自动跳过片头 `no_pose`/缺踝帧估计低位基线。
- **实战式基线统一**：踢腿动作起止实战式窗口统一由 `motion_in.stable` 与 `settled_stance_windows` 输出完整边界窗口（未闭合末端不输出 `stance:end`），无手部升高/脚未稳时的 `torso` 兜底伪窗口。在全部 14 个 VAL 样本 × 正侧双视角 × `full`/`heavy`（共 112 路检查）上，起止实战式窗口均无截断碎窗（`< ceil(stance_window_seconds * 30)` 数量为 **0**）。
- **切分命中率（生产 `evaluate_series` 与 `exam_pool.action_side_repetitions`）**：
  - `full` 模型：`step_front_low_kick` **47/47（100%，`{2: 6, 1: 41}`）**、`rear_low_kick` **17/17（100%，`{2: 6, 1: 11}`）**，错配 **0**；
  - `heavy` 模型：`step_front_low_kick` **47/47（100%，`{2: 6, 1: 41}`）**（含复合膝高有效兜底修复 `B_S3` 第 2 脚脚踝遮挡）、`rear_low_kick` **17/17（100%，`{2: 6, 1: 11}`）**，错配 **0**；
  - 专项边界：`D24_P1/P2` 均正确切出 **1** 次；`C96_P1/P2` 原地收脚均正常闭合（`incompleteRecovery=False`）。

## 3. 生产链路全量 42 实例分模型资格定级表

按仓库红线分模型（`full` 与 `heavy`）独立统计与定级，**全量使用总分母（`VAL = val_n + val_un`、`TGT = tgt_n + tgt_un`）计入 `unable`**，且 **不设任何未获用户批准的 `trial` 旁路**：
- **授予 `enabled`**：仅当对应模型下满足 `VAL FP <= 10%`（`val_un = 0`）、`TGT TP >= 70%` 且命中 `>= 2` 名不同演示者；
- **记为 `validation_pending`**：`VAL FP <= 10%`，但当前缺少对应错例或错例不足 `2` 名演示者（暂不启用）；
- **记为 `calibration_failed`**：误报率 `> 10%`、`VAL` 含 `unable`、目标检出 `< 70%`（含因 `unable` 拉低总检出）或单视角投影混叠项（阻断为 `pending_rule`，锁定阈值 `foot_flexed < 165°`、`body_lean > 35°`、`guard_elbow > 30°` 绝不放宽强行凑过）。

## 4. 关键工程决策与已知限制

1. **老规则误报收敛、单一真源与遮挡严谨性**：
   - 旧实现中 `foot_flexed`、`hip_turn` 等未接入 `qualification.py`，导致全模型直通误报；本轮通过 `kick_policy.py` 按 `full`/`heavy` 各自实证结果独立授信，`lite` 及未验模型统一阻断为 `validation_pending`，**不存在任何未经授权的 `trial` 放行**。
   - `arm_downward_extension` 与 `measure_arm_swing_down` 强制要求肩-肘-腕 3 点同时有效（`valid = valid_drop & valid_ang`），当肘部遮挡即使手腕看似未下垂时也严格输出 `unable`，杜绝“残缺关键点静默通过”。
   - `kicking_leg_side_safe` 仅在双侧踝关节同时有效的帧集合内统计左右脚互换比例，避免大比例遮挡稀释互换检测。
   - 正面 `guard_elbow` 采用独立策略 `upper_arm_torso_flare`，不改动直拳既有 `elbow_shoulder_height`；低鞭腿 `guard_shoulder`/`guard_back` 按解剖朝向分视角检验（前腿进攻看 `side`，后腿进攻看 `front`）。
2. **未通过项物理/视图瓶颈总结**：
   - `pivot_heel`（脚跟轴转）：侧视 2D 相机下足尖-脚跟投影间距受站位远近、鞋长与 `heavy` 关键点高遮挡（`6/11 un`）影响严重，正误样本混叠。
   - `foot_flexed`（`< 165°`）：正常发力瞬间及后腿远侧遮挡时，2D 投影下脚尖-踝角自然小于 `165°`，且 MediaPipe 对远侧被遮挡脚部仍给出高置信度导致无法靠 `valid_mask` 隔离。
   - `hip_turn`（未翻髋）与 `guard_elbow`（`> 30°`）：正面单目 2D 投影中，自然实战式护架的大臂与躯干夹角多大于 `30°`，且髋部侧转幅度受上步切角透视干扰，正误重叠明显。
   - `guard_jaw`：后鞭腿转体鞭打时前手随躯干扭转远离嘴部正面投影，与静止实战式阈值不兼容，且缺少对应错例视频。
3. **后续建议**：
   - 若需将后鞭腿 `guard_shoulder` 升级为 `enabled`，需补充至少第 2 名演示者的前护手掉肩错例视频；若需启用 `kick_height` 与后鞭腿 `body_lean`，需补充踢高/踢低及原地后低鞭腿侧倾错例视频。
