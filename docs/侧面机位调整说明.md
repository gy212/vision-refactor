# 侧面机位调整说明（给甲方）

> 2026-10-22 起草，对应 `docs/规则检出修复计划.md` 步骤 2（D-19，待甲方确认）。第二批样本、教师模板和以后的考试都按本说明摆放摄像头。
>
> 本说明没有勾选框（WPS 会把勾选框显示错）。需要甲方填写的地方都是表格，在空格里写字或打 √ 即可。

## 一、为什么要换位置

现在的侧面摄像头在考生**左后方**，斜着拍。考生摆左式时胸口朝右、后背朝左，所以侧面拍到的主要是后背：护脸的右手、右腿几乎看不到。第一批样本里，侧面能看清右肘、右腕的画面只有 3%～21%，和右手、右腿有关的检查在侧面基本做不了。

侧面摄像头换到考生**右侧**以后，拍到的是考生的胸口一侧，右手、右腿都在靠近镜头的一边。

正面摄像头不动。

## 二、摆放要求

下面"左""右"都按考生自己的左右说（考生面对正面摄像头站在起点上）。

| 项目 | 要求 |
|---|---|
| 位置 | 考生**右手边** |
| 方向 | 和正面摄像头的拍摄方向成 90°（直角），镜头正对考生身体的右侧；不要放在考生身后斜着拍，也不要放在考生前方斜着拍 |
| 高度 | 镜头大约在考生胸口的高度，镜头保持水平，不要明显向上或向下仰俯 |
| 距离 | 考生站在起点摆实战式时，从头顶到脚底约占画面高度的七成，上下都留出空 |
| 左右余量 | 上步会让考生往前走半步到一步。在侧面画面里，考生是**向画面右边**横着移动的，所以起点要放在画面中间偏左，保证上步以后脚和前手仍在画面里 |
| 背景 | 立式空调不要出现在考生身后（第一批的侧面画面里，空调正好在考生身后）。背景里也不要有镜子、反光的玻璃、人形的海报或走动的人 |
| 画面 | 侧面横屏 1920×1080；正面仍是竖屏 1080×1920 |
| 固定 | 摄像头用支架固定，拍摄期间不挪动、不碰 |

**怎么摆成 90°**：在地上贴一个起点标记，从起点向正面摄像头贴一条线；侧面摄像头放在从起点出发、和这条线垂直的另一条线上。地垫上已有的胶带格线可以直接用来对齐。

## 三、摆好以后在系统里检查

打开系统，选好正面、侧面两个摄像头，请一个人在起点摆左式（左手、左脚在前，右手护脸），看预览：

| 检查项 | 正确的样子 |
|---|---|
| 侧面画面里人朝哪边 | 考生的脸和前手朝**画面右边** |
| 侧面能看到什么 | 能看到胸口一侧、护在下颚的右手和右腿；看不到后背 |
| 侧面画面的范围 | 让考生在起点上步做一次直拳组合，再退回起点：整个过程中头顶到两只脚都在画面里 |
| 正面画面 | 人是正的（站着，不是横躺）；如果是横的，在开始录制**之前**改好旋转。录制中改旋转，要到下一段才生效 |
| 正面的黄框 | 正面预览里的黄框（判断考生是否到位的范围）要盖住考生从起点上步、再退回的整个范围；上步时人一直在黄框里 |

侧面画面里如果考生的脸朝画面**左边**、看到的是后背，说明摄像头放在了考生左边，请换到右边。

## 五、教师重录模板

侧面摄像头换边以后，侧面画面里人的朝向反过来了，原来侧面拍的模板不能再用。另外 4 个新的考试动作还没有模板。所以请教师在新位置重录模板。

**录哪些**：5 个考试动作各录 1 段，每段同时录正面和侧面：

| 动作 | 说明 |
|---|---|
| 上步前后手直拳组合 | 新动作 |
| 上步前后手摆拳组合 | 新动作 |
| 上步前后手勾拳组合 | 新动作 |
| 上步前低鞭腿 | 新动作 |
| 原地后低鞭腿 | 侧面换边，需要重录 |

**怎么录**：

| 顺序 | 做什么 |
|---|---|
| 1 | 两个摄像头按本说明摆好，和考场一致 |
| 2 | 用我们新发的系统版本，进入学生练习模式，选好正面、侧面摄像头；学号填 T1，动作按《样本视频采集清单》第二节的对照表选，然后点"开始" |
| 3 | 教师走进正面的黄框站稳，听到系统播报"开始"以后再做动作 |
| 4 | 在起点直立 2 秒，摆实战式保持 2 秒 |
| 5 | 动作只做 **1 次**：从起点上步做动作（后低鞭腿原地踢），做完边退回起点边恢复实战式 |
| 6 | 保持实战式 2 秒，走出黄框或点"结束"，听到"结束" |
| 7 | 回放检查：两路都有画面，动作完整在画面里，没有别人入画；不满意就重录 |

模板只做 1 次动作，这一点和样本不一样（样本每段做 2 次）。练习模式录完会给出动作问题说明，录模板时不用管它。

**交给我们**：把每个动作录好的片段目录原样发给我们，并告诉我们哪个目录是哪个动作。模板文件由我们生成：新动作的模板名要和系统里新加的动作名一致，我们生成好以后随新版本一起发回。收到新模板之前，考试仍用原来的模板；换上新模板时，原来侧面的模板要从考试的侧面模板池里移除。
