# 实战式站距试用范围调整

最终采用 **0.70～1.35 倍**，原范围为 0.8～1.2 倍。用户授权根据样本自行选择合理数值，并明确选择“优先减少误报”。这是现有测量方法的试用范围，不是重新定义教师的站姿标准。

## 调整依据

客户报告 `16_后手直拳_练习分析报告(1).html` 的开始实战式，站距比值为 1.21～1.25，中位数 1.22，因此被原 1.2 上限提醒。按新范围，这组已记录的数值不再触发站距异常。

复用 7 段实战式的 full 姿态缓存：教师及两名执行者的正确对照各一段，另有 C7、C8 两名执行者各一段。按同一阶段、同一测量方法比较少量候选范围，没有重新推理或重跑其他动作。

| 候选范围 | 3 段正确对照中仍提示异常的段数 | 4 段标注错误素材中提示异常的段数 |
|---|---:|---:|
| 原 0.8～1.2 | 2 | 4 |
| 客户初提 1.0～1.35 | 1 | 3 |
| 0.9～1.35 | 1 | 3 |
| 0.8～1.35 | 1 | 3 |
| 最终 0.7～1.35 | 0 | 3 |

以上按录像计数，不把开始、结束的重复检查当成两份样本。错误素材的标签与选帧存在方向矛盾，因此第二列以外的数字只说明是否出现提醒，不能宣称缺陷检出率达标。

- 下限选 0.70：P1 正确对照的中位数约 0.73，原下限 0.8 及候选下限 0.9、1.0 都会提醒。0.70 下，该样本的异常帧占比未达到触发要求。
- 上限选 1.35：教师正确示范的最大值约 1.301，原上限 1.2 会误报；1.35 给这组正确示范留出少量余量，也覆盖客户报告的 1.21～1.25。
- 不继续围绕剩余错误样本调数值：C8 P1 约 1.25～1.30，与正确示范重叠，仅调整同一比值的上下限无法可靠区分。

## 真实样本结果与限制

| 样本 | 站距比值中位数 | 原范围 | 最终范围 |
|---|---:|---|---|
| 教师正确示范 | 1.298 | 提示 | 不提示 |
| P1 正确对照 | 0.730 | 提示 | 不提示 |
| P2 正确对照 | 1.048 | 不提示 | 不提示 |
| C7 P1，清单标为过宽 | 0.654 | 提示 | 提示 |
| C7 P2，清单标为过宽 | 0.397 | 提示 | 提示 |
| C8 P1，清单标为过窄 | 1.280 | 提示 | 不提示 |
| C8 P2，清单标为过窄 | 0.633 | 提示 | 提示 |

核对了 P1 正确对照、C7、C8 的实际代表帧。C7 选中画面双脚靠近，C8 选中画面前后分开，与清单的过宽、过窄方向不一致。尚不能判定是素材标注问题还是所取阶段未覆盖目标姿势，不能把这些标签直接当作可靠的调参依据。C7 的提醒由偏小的测量值触发，也不能声称正确检出了“过宽”。

当前测量仍受机位投影、前后错步和关键点偏差影响。三段正确对照不再提示，不代表对其他执行者的误报率已满足上线要求。C8 P1 仍落在允许区间内；本次按用户选择优先减少误报，保留此限制，继续试用。未重新验证 heavy 模型准确率。

## 公共规则与验证

范围放在公共参数中，独立实战式及所有动作的开始、结束实战式统一使用。报告标准、试用说明与默认参数引用同一数值，规则版本为 v5.16。站距测量也接入公共参数应用路径，旧配置文件中的 0.8～1.2 不会盖过新范围，避免报告与实际判断不一致。

定向与核心门禁 **102 项通过**，覆盖 0.69、0.75、1.22、1.40 的受控站距，及独立实战式、后手直拳、组合、练习、公共规则、考试报告、batch。保留缺少机位或关键点时的无法判断契约。7 条警告为已有模块体量预警。Golden 只同步两条站距试用说明，模板、分数及技术指标未重建。格式、空白检查通过。

客户仍只有 HTML，未重跑其原片，也未改写原报告；客户新结论仅按报告已记录数值推算。重新生成报告需要使用新代码分析原视频。
