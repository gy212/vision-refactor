# 2026-11-05 直拳逐项改进

用户已要求按逐项回复改进，并重跑原录像。先给报告，用户认可后再提PR。

本次版本为v5.7。原录像认出2次组合拳。0项提醒，14项已查且没发现问题，23项未自动检查。原Excel及老师意见没有改写。

## 改了什么

按检查部位选面。左拳打出时的右肘用侧面。右拳打出时的左手用正面。单面项目不再混入另一面的判断。身体朝向仍参考两面肩宽。这里是按当前拍法指定合适的一面，不是每张画面随意换面。

站姿检查改取最早一段站稳的画面。优先看清手腕和嘴，再取稳定段中间。选画面时不读任何检查项的对错。动作次数、起止和出拳时间没有改。先找动作与最后检查站姿，各有自己的画面范围。

开始站姿从约9.87秒改到11.57～11.77秒。结束站姿取20.60～20.80秒。这里写的是正面。侧面按自己的稳定画面选。原来的护下巴误报消失，判断距离没有放宽。

只新增两项自动检查：左拳打出过程、打到头时的右肘抬高。两种识别方式分别通过。其余新办法已写入并试跑；没过核对的继续停用。

删掉开始和结束的胸腹抬头检查，以及拳头横竖检查，共3项。清单从40项变成37项。默认方式开启14项，另一种开启12项。差别仍是身体朝向。

过程和结束独立判断。相同的护手提醒可以合并展示。原记录、两项结论、图片依据和检查计数保留。结束已恢复时，不复制过程的错误。
