## 这次改了什么

1. 右护手后拉改看肘有没有明显退到身体后方。沿肩和腿根画身体线，并随身体倾斜修正。正常从身前收回身旁不再算后拉。距离仍为肩到腿根长度的18%。只用侧面。
2. 打右拳时，左护手肘改用正面。两段C32录像的左肘在正面能找到，侧面看不清不能直接否定整项。正面使用程序给出的前后位置试算，仍可能漏查。此项只登记试用。
3. 伸直检查改成每次拳单独判断是否达到177°。同一次拳已经伸直，前后收拳的弯肘不再直接否定它。一次拳伸直不能替另一次拳通过。缺失画面不算通过。
4. 其余已经写好的判法进入试用。保存“试用”标记。练习页面、普通报告、考试与离线的规则说明都会显示标记。不会把试用改写为已核对。
