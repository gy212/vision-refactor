# 样本视频采集清单

> 2026-10-14 起草。请甲方按本清单拍摄样本视频，用于：D-11 的 body_core 标定（issue #23），D-3、D-5 统一规则后的现场阈值微调（issue #21、#22），以及以后的回归测试。旧样本（`docs/yolo_eval_samples.json` 登记的 6 段）都是 720×1280 竖屏，不符合现行拍摄规格，不再使用。

## 一、拍摄规格

每段都必须满足：

- [ ] 用本系统的学生练习模式双摄录制，不用手机或其它软件。这样分辨率、帧率、编码和正侧同步都与实际使用一致。
- [ ] 正面竖屏 1080×1920，侧面横屏 1920×1080，约 30 fps。
- [ ] 摄像头型号、机位、高度、距离和光照与考场一致，拍摄期间不挪动。
- [ ] 画面中只有被拍者一人，从头顶到脚尖始终完整入画；背景中没有镜子，也没有其他人走动。
- [ ] 一律左式：左手、左脚在前，右手护脸。
- [ ] 每段的流程：直立 2 秒 → 摆实战式并保持 2 秒 → 做动作 → 回到实战式并保持 2 秒 → 结束。只拍实战式的段，实战式保持 5 秒。
- [ ] 同一次录制的正面、侧面两路成对保存，不单独补拍某一路。
- [ ] 被拍者已同意录像用于本系统的标定与测试（由甲方负责）。

## 二、交付

- 系统录制目录原样交付，不剪辑、不转码、不改文件名。
- 另附一张标注表，每一对视频一行：

| 列 | 内容 |
|---|---|
| 片段目录 | 系统生成的目录名 |
| 人员编号 | 匿名编号，如 T1（教师）、S1–S5（学员） |
| 动作 | 用下文清单中的动作名 |
| 类别 | A 标准示范 / B 标定 / C 错误样本 / D 边界 |
| 故意做错的项 | C 类填下文的错误项编号，其余填"无" |
| 教师判定 | 教师看录像后，逐项写"对""错"或"看不清"，以教师判定为准（故意做错时也可能连带出错） |

- 视频不进 git 仓库。收到后放在仓库外的固定目录，路径登记进新的样本清单，取代 `docs/yolo_eval_samples.json`。

## 三、清单

"考试动作"指考试模板池里的全部动作，具体名单请甲方提供。下面的数字以每对视频（正面 + 侧面）为单位。

### A 标准示范（教师，每项 1 对）

- [ ] 实战式
- [ ] 前手直拳、后手直拳、前后手直拳组合
- [ ] 前手摆拳、后手摆拳、前后手摆拳组合
- [ ] 前低鞭腿、后低鞭腿
- [ ] 考试动作中不在上面的其它动作，每个 1 对

### B 标定样本（D-11）

- [ ] 至少 5 名学员，水平高低都要有；每人把每个考试动作正常做 1 遍，每个动作 1 对

### C 错误样本（D-3、D-5 阈值微调）

每段只故意做错一项，其余动作要领保持正确。每项至少 2 人各拍 1 对；每组另拍 1 对完全正确的作对照。

实战式（只拍实战式）：

- [ ] C1 前手肘角过直（明显大于 135°）
- [ ] C2 前手肘角过弯（明显小于 90°）
- [ ] C3 前手拳峰明显低于鼻尖
- [ ] C4 前手拳峰明显高于鼻尖
- [ ] C5 后手离开下颚和肋骨
- [ ] C6 双腿伸直
- [ ] C7 站距过宽
- [ ] C8 站距过窄
- [ ] C9 两脚内八
- [ ] C10 两脚外八
- [ ] C11 躯干正对前方

出拳（前手直拳、后手直拳、前手摆拳、后手摆拳，四个动作分别拍）：

- [ ] C12 护手掉手
- [ ] C13 护手向后拉
- [ ] C14 护手抬肘
- [ ] C15 出拳不与肩齐平
- [ ] C16 后手摆拳打完，前手不回收护下颚（只拍后手摆拳）

低鞭腿（前低鞭腿、后低鞭腿，两个动作分别拍）：

- [ ] C17 勾脚尖，脚背不绷直
- [ ] C18 不翻胯
- [ ] C19 踢腿同侧手不向下甩
- [ ] C20 后低鞭腿踢完，前手不回收护下颚（只拍后低鞭腿）

立拳、含胸收腹两项目前无法从关键点可靠判定，不用拍。

### D 边界样本（可选，用于检查补帧处理，D-2）

- [ ] 2 对：宽松深色衣服
- [ ] 2 对：光线偏暗
- [ ] 2 对：动作中途手或脚短暂出画

## 四、数量估算

| 类别 | 对数 |
|---|---|
| A | 9 + 其它考试动作数 |
| B | 5 × 考试动作数 |
| C | 实战式 (11 + 1) × 2 = 24；出拳 (4 × 4 + 1 + 4) × 2 = 42；鞭腿 (2 × 3 + 1 + 2) × 2 = 18；合计 84 |
| D | 6（可选） |

每对 10–20 秒。以考试动作 10 个计，共约 160 对，按每对 1 分钟（含准备）估算，约 3 小时可拍完。
