## 二、清单 CSV 格式

UTF-8（可带 BOM），一行是一对视频（正面 `front.mp4` + 侧面 `side.mp4`）的一次标注。表头用英文键或括号里的中文名都可以，列的顺序不限。

| 列 | 中文名 | 内容 |
|---|---|---|
| `pair_id` | 样本编号 | 对的唯一编号，必填 |
| `repetition` | 第几次 | 空或正整数。第一批留空；第二批每段做 2 次，同一对写两行（1、2），对级字段必须一致 |
| `segment_dir` | 片段目录 | 相对样本根目录，必填 |
| `category` | 类别 | A 标准示范 / B 标定 / C 错误样本 / D 边界，必填 |
| `person` | 人员编号 | 匿名编号，如 T1、S1 |
| `action` | 动作 | 动作名（中文），只作记录 |
| `rule_actions` | 规则动作 | v5 目录的动作键（如 `straight_combo`），多个用 `\|` 分隔；空 = 不评估 |
| `error_item` | 故意做错的项 | 第一个空白前是项编号（如 `C7 站距过宽`）；空或"无" = 没有故意做错 |
| `expected_codes` | 预期检查项 | 这个错误应触发的检查项 code，多个用 `\|` 分隔 |
| `teacher_verdict` | 教师判定 | 空 = 未判定；`对` / `错` / `看不清` 是整体判定；也可逐项写 `C7=错;C1=对`（逐项优先，`*=对` 表示其余项） |
| `front_rotation` | 正面旋转 | 推理前把正面画面顺时针转的度数：0 / 90 / 180 / 270，缺省 0 |
| `note` | 备注 | 只作记录 |

甲方交的标注表（`docs/样本视频采集清单.md` 第三节）是一对一行、"第 1 次教师判定""第 2 次教师判定"两列；入库前拆成每次一行，并补上 `rule_actions`、`expected_codes`。

## 三、样本口径

逐次切分（修复计划步骤 8）落地之前，评估按整段进行，"第几次"只参与标注汇总：

- **正确样本**（算误报率）：没有故意做错的项，教师没有把任何项判为"错"或"看不清"。未判定时按推定正确计。
- **错误样本**（算检出率）：有故意做错的项，教师没有把这一项判为"对"或"看不清"。未判定时按推定错误计。多行时任一次满足即可。
- 其余不计入两类指标，例如教师判定故意项其实做对了、正确样本上教师判出了别的错。

## 四、用法

```powershell
$env:VISION_SAMPLES = "D:\VisionSamples\2026-10-16_client_batch1"
.\.venv\Scripts\python.exe -m analysis.sample_eval run --manifest docs/samples/2026-10-16_client_batch1.csv --out outputs/sample_eval/before --workers 6
# 修改规则后，在改动分支上再跑一次
.\.venv\Scripts\python.exe -m analysis.sample_eval run --manifest docs/samples/2026-10-16_client_batch1.csv --out outputs/sample_eval/after --workers 6
.\.venv\Scripts\python.exe -m analysis.sample_eval compare --before outputs/sample_eval/before --after outputs/sample_eval/after --out outputs/sample_eval/compare.md
```

- 姿态缓存默认在 `outputs/sample_eval/pose_cache/<样本根目录名>/`，修改前后的两次运行共用，缓存键（版本、模型、旋转、视频路径与大小）变了才重新提取。中断后再跑会从缺的视频续上。
- 模型从仓库的 `models/` 读（`--models-dir` 可改），子进程不下载模型；缺 heavy 模型时先在桌面程序的模型管理里安装。
- 运行目录里有 `checks.csv`（逐对逐检查项）、`phases.csv`（逐对逐动作的相位与对齐）、`results/`（每对每动作的完整练习结果）、`run.json` 和 `report.md`。`compare` 只读运行目录，不重新推理。
- 规则 PR 把 `compare` 生成的对比报告附在 PR 说明里（修复计划第四节）。
