### 入口对应关系

- 练习：Tk `practice_analysis`、`services/practice_history` → `analyze_practice/evaluate_series`。
- 考试：`services/analyze.score_segment` → `exam_pool.rule_reports` → `judge_views`；规则提示和模板分数各自保留语义。
- 批处理：`batch_dual_compare` → `services.compare_dual` → `matching/dual` → `judge_view/judge_views`。
- 报告：规则结果 → `adapters` → 保存记录 → `practice_model` → 文本、HTML、Tk结果面板与证据窗口。
- 技术指标与其他分析已有几何、有效点等复用，其独有采样和计算不因整理规则而改变。

### 动作覆盖清单

直接读取现有规则清单。左右式、`full/heavy` 的检查数量一致，资格和判法仍需按各自条件核对。

| 动作 | 每份检查数 |
|---|---:|
| 实战式 | 16 |
| 上步前后手直拳组合 | 37 |
| 前后手直拳组合 | 40 |
| 前后手摆拳组合 | 37 |
| 前手直拳 | 26 |
| 后手直拳 | 30 |
| 前手摆拳 | 24 |
| 后手摆拳 | 29 |
| 前低鞭腿 | 28 |
| 后低鞭腿 | 24 |

每个动作覆盖开始/结束站姿及其实际动作阶段；区分前后手与左右身体侧。上步组合另外具有出拳前和收回后阶段。

### 必须保留的业务差异

- 腕肩高度与腕鼻高度、脚间距与脚向夹角分别命名；复用基础几何，保留各自标准。
- 上步组合已批准的80°、175°、15°及试用范围准确迁移，不自动推广。
- 普通往返事件和上步事件的起点、缺帧处理、未回收保持策略明确表达；组合配对仍由组合负责。
- 主要展示正面的检查可能仍需双面原始数据；其证据必须包括实际依赖的机位。
- 逐次伸直汇总的已知限制单列，不能在职责迁移时暗改判法。
- 资格不跨模型、阶段自动继承，历史结果不借当前规则补造已记录事实。
