# 录制性能测试操作说明

这个测试检查录制用的电脑按现在的设置能否稳定地录制两路 1080p 画面。请在平时录制考试视频的那台电脑上做。全程大约 3 分钟（分五段），不需要有人站在摄像头前；最后一段会在主界面上显示摄像头画面，这是正常的。

## 操作步骤

| 步骤 | 做什么 |
|---|---|
| 1 | 笔记本请插上电源。关掉其它占用电脑的程序（视频软件、会议软件、浏览器里的视频等）。 |
| 2 | 插好平时录制用的两个摄像头，打开桌面程序 vision_ui.exe。 |
| 3 | 在主界面左侧选好「第一摄像头（正面）」和「第二摄像头（侧面，可选）」，旋转、「录制时识别骨架」等设置都和平时录制时一样。不用点「开始」。 |
| 4 | 在主界面上同时按键盘的 Ctrl + Shift + B 三个键，会弹出「录制性能测试」窗口。 |
| 5 | 点「开始测试」。进度条走完前不要拔摄像头、不要关程序，也尽量不要用电脑做别的事。 |
| 6 | 测试结束后，窗口最上面用大字写着结论：按当前设置能否稳定录像（绿色是能，橙色是能但余量小，红色是不能，灰色是测试不完整）。下面是给技术人员看的各段明细和报告文件的完整路径。 |
| 7 | 把报告文件发给技术人员（见下一节）。 |

## 报告文件在哪里

报告保存在这台电脑的**桌面**上，文件名是：

    录制性能测试_日期_时间.json

例如 `录制性能测试_20261021_093005.json`（2026 年 10 月 21 日 9 点 30 分 05 秒做的测试）。

找不到时可以用测试窗口下方的两个按钮：

| 按钮 | 作用 |
|---|---|
| 打开所在文件夹 | 打开桌面文件夹，并自动选中这个报告文件，直接拖进微信即可发送。 |
| 复制路径 | 复制报告文件的完整路径，可以粘贴到微信「文件」的选择框里。 |

少数电脑的桌面不能写入，这时报告会存到 `C:\Users\<用户名>\AppData\Local\VisionSanda\录制性能测试\` 文件夹，窗口里显示的路径就是实际位置，以窗口显示为准。

## 常见情况

| 看到的提示 | 怎么办 |
|---|---|
| 按 Ctrl + Shift + B 没反应 | 先用鼠标点一下主界面（让主界面处于选中状态），再按一次。 |
| 请先在主界面点「停止」结束预览 | 主界面正在预览，点「停止」后再按 Ctrl + Shift + B。 |
| 请先退出考试或学生练习 | 关掉考试窗口或退出学生练习，回到主界面再测试。 |
| 请先在主界面选择摄像头 | 回到第 3 步选好摄像头。 |
| 磁盘只剩 … GB | 测试时会临时写入约 1 GB 视频（测完自动删除），请清理录制目录所在磁盘后再测。 |
| 结果里写着「无法打开设备，可能被其他程序占用」 | 关掉微信视频、会议软件、浏览器等可能在用摄像头的程序；仍不行就拔下摄像头重新插上，再测一次。 |
| 结论写着「不能稳定录像」，或明细里有「本段有问题」 | 这是正常的测试结果，不是程序出错，照常把报告发过来即可。 |
| 窗口里写着「没有接电源」「节电模式开着」或「最佳能效」 | 插上电源，在 Windows 设置→系统→电源里关掉节电、电源模式选「最佳性能」，再测一次，两份报告都发过来。 |
| 结论里写着「缺少 Lite 模型」或「缺少骨架识别模型」 | 在主界面的设置→模型管理里安装提示的模型，再测一次。缺 Lite 模型时考试和学生练习也开不了。 |
| 测试中途出错或被取消 | 已经测到的部分也会保存成报告，同样发过来；方便的话再测一次。 |

测试录下的视频会自动删除，不会留在录制目录里，也不会影响已有的考试记录和成绩。
