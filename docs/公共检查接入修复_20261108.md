# 公共检查接入修复

## 问题从哪里来

客户用 v5.13 测试单独后手直拳，报告有 10 项无法判断、8 项未自动检查。结束瞬间多项显示 `0/5` 或 `2/5` 有效帧，无法看到实际选中的画面。客户只提供 HTML，没有原录像、姿态数据和完整记录，因此不能确认这次 8.600 秒的出拳峰值是否选对。

代码与受控输入确认了三个缺陷：

- 公共检查已经存在，但检查标准仍绑定整套动作。上步组合使用新标准，单直拳和普通组合仍使用旧标准。同一后手直拳换一个练习入口，选机位和测量方法就变了。
- 单拳伸肘检查中，侧面即使 5 帧全部有效，正面只有 2 帧有效也会阻塞整项。旧的相对护位测量还要求全部起始参照帧有效，只坏一帧就能把完整动作的测量变成 `0/5`。
- 无法判断的项目丢弃了已取到的画面和部分测量，只剩一句笼统提示。另有六个出拳侧占位项目仍写“需实现”，没有接上已有的出拳前、收回后检查。

## 业务归属与修复范围

检查属于实战式或基础动作段，不属于某个组合名称。实战式的相同检查在所有动作里共用；前手直拳和后手直拳在单拳、普通组合、上步组合里共用。组合编排、评分方式、验证资格各自声明，不用一个开关控制所有事情。

同一段、阶段、身体部位和模型使用已有的逐项验证记录。复用算法不等于整个动作已经通过准确率验收，试用项目继续明确标注试用，模型或阶段不适用的资格不冒用。

按三个步骤完成修复，每步单独提交：

1. 按基础段接入公共测量、机位选择和检查清单，淘汰同类旧路径；修正参照一帧失效连坐整段的问题。
2. 单拳和组合接入公共直拳事件、出拳前及收回后阶段，实战式共用稳定画面的选择。组合保留组合配对职责，单拳不受“两次组合”的要求限制。
3. 所有分析出口保存无法判断时的真实取帧、已有数值和具体缺失原因，并在报告中提供可查看的现场依据。

## 实际验证结果

复用五组真实录像的既有姿态缓存，前后使用同一输入。本次没有重新推理，也没有为通过样本修改公共标准的阈值；单拳实际采用了公共标准原有的参数和试用状态，例如伸肘使用 177°、站姿膝角使用 175°。

| 素材与模型 | 修改前：疑似 / 未发现 / 无法判断 / 未检查 | 修改后 | 识别事件 |
|---|---|---|---|
| 教师正确上步组合，full | 0 / 37 / 0 / 0 | 0 / 37 / 0 / 0 | 4 → 4 |
| C35 出拳前预摆，full | 14 / 23 / 0 / 0 | 13 / 24 / 0 / 0 | 3 → 3 |
| C13 后手单拳，heavy | 8 / 3 / 11 / 8 | 6 / 6 / 16 / 0 | 1 → 1 |
| C13 前手单拳，heavy | 8 / 4 / 11 / 3 | 8 / 10 / 7 / 0 | 1 → 1 |
| A 普通直拳组合，heavy | 7 / 4 / 20 / 9 | 3 / 20 / 14 / 0 | 5 → 5 |

- C35 的出拳预摆、过程和结束检查保留原结论。少一条提醒来自开始实战式改选稳定画面，膝角中位数从 175.51° 变为 173.92°，175° 标准不变。
- 普通组合原来的识别顺序不齐，会导致整个动作阶段被丢弃；现在保留已经识别的独立段。表中的事件数是算法观测结果，不冒充人工计数标签。
- 后手单拳的 16 项无法判断中，7 项确有点位或参照不足；另外 9 项没有收回后或结束护位阶段。旧版原本就没有结束护位窗口，已有 7 项结束检查无法判断，另有头胸项目未检查；新版多出独立的后手护下颚、收回后检查，因此不能把 9 项都算作新丢帧。
- 两份单拳分别通过练习、公共规则、考试规则报告和双流 batch：每个入口只识别一次，序列化后完整共享记录一致，考试和 batch 各保存一份共享记录。
- 后手、前手正式 HTML 各嵌入 13 张图片。后手报告中 7 张展示无法判断时实际选中的画面，并注明具体缺点。已对照原片核对两份单拳的峰值，分别为 2.633 秒和 7.667 秒。

本地结果在 `outputs/shared-rule-consumers/validation/实测报告.md`，三份正式报告在同目录的 `reports/`。原视频、缓存和输出不提交仓库。

## 自动化验证与旧测试替换

- 核心门禁、六项跨动作跨入口行为和共享记录保存契约：75 项通过。初次有两项 golden 仍期待旧实战式规则，已只更新 `golden.json` 的正、侧规则结果并复跑通过；模板、分数、关节误差、技术指标保持原基准。
- 规则定向：74 项通过；计时及逐次覆盖：60 项通过，相关练习计时另 4 项通过。
- 证据、选图与呈现：51 项通过、1 项因 Linux 缺少 Tk 跳过；报告导出 27 项通过，Windows 结果页 18 项通过。
- 上述套件有交叉，不把数字相加宣称总用例数。格式和空白检查通过。

旧的“新参数只影响上步组合”“普通直拳继续用旧目录”“换标准后全部阻塞”断言已删除，改为验证相同基础段在单拳与组合里使用相同定义、参数和逐项资格。缺阶段仍不得借其他画面；已选中但无法测量的阶段则必须保留诊断画面。图片顺序按阶段主图优先，不能再断言参照图排在另一阶段问题图之前。

## 验证边界

客户原片缺失，本次不能宣称已重现或修正客户报告的 8.600 秒峰值。第一批 A 素材没有教师逐项正确性确认，两个 C13 是错误演示；这些样本证明业务接通，不构成新准确率资格。原有试用检查的误报、漏报风险继续保留。

实际素材的 batch 验证用最小替身隔离模板分数，姿态、计时、规则、证据和序列化走真实代码；考试验证公共规则报告出口，不宣称验收整场考试评分。未进行 Windows 打包、实体摄像头或打印验收，也未重跑全量历史差分。
